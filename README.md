# LinkedIn AI Reply Pro

An AI-powered Chrome extension that helps B2B sales professionals, recruiters, and marketers generate highly engaging and natural-sounding comments for LinkedIn posts in one click.

## 🚀 Features
* **One-Click Extraction**: Instantly grab the text of any LinkedIn post or webpage.
* **AI-Powered Comments**: Generate non-robotic, professional English replies using the DeepSeek API.
* **High Conversion Prompts**: Built-in prompts designed specifically for B2B sales to encourage replies.
* **Usage Limits**: Integrated with local storage to track free daily usage (3 per day).

## 🛠️ Tech Stack
* **Framework**: [Plasmo](https://www.plasmo.com/) (Browser Extension Framework)
* **Frontend**: React + TypeScript
* **AI Model**: DeepSeek API

## 💡 How it Works
1. Select the text of a post on LinkedIn.
2. Open the extension and click "Extract".
3. Click "Generate" and watch the AI write a perfect reply.
4. Copy and paste it directly into the LinkedIn comment box.
